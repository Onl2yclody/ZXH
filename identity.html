PROJECT DETAIL / 02

艺悦楼
导视设计

IDENTITY / WAYFINDING DESIGN
主题 / THEME

北京理工大学珠海学院艺悦楼导视设计

项目说明 / DESCRIPTION

以黑白简约的视觉语言建立校园导视系统，将楼层、方向、空间名称与图标组织为可组合的模块，在不同尺度与场景中保持清晰识别。

01 / 主题立项

针对艺悦楼采光不足、拐角多、通道偏窄、出入口复杂及分区指引较弱的问题，围绕学生、教职工和外来访客建立设计定位，兼顾教学、研究、办公、展示与社交功能。

02 / 制作过程

通过案例研究与环境分析确定方向，制定图标、箭头、分区字母和数字清单，再展开室外、建筑入口与室内导视规划。以下展示结课报告的研究与元素设计记录。

03 / 设计思路

采用黑白简约风，以铝制结构与黑色镂空波点底板构成材料方案。文字、图标、楼层数字与箭头按模块组合，像搭积木一样适配门牌、悬挂标识、墙面标牌与立式导视。

04 / 问题与设计应对

调研指出白色标识与白墙融合、分区指引偏弱、多入口容易迷失等问题。方案通过黑白对比、分区字母、箭头与功能图标组织信息。报告未记录实际安装或用户测试结果，因此不将设计意图写成已验证的改善效果。

05 / 成品与场景效果

八组原图与效果图对照展示导视在校园空间中的应用设想。保留原报告的对照关系；这些为方案效果图，并非施工落地照片。
