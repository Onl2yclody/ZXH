PROJECT DETAIL / 07

聊斋志异
聂小倩

NIE XIAOQIAN · ILLUSTRATION DESIGN
主题 / THEME

聊斋志异·聂小倩 / 硬切分风格角色插画

作者 / AUTHOR

钟锡汉 ZHONGXIHAN

项目说明 / DESCRIPTION

以硬切分色块塑造古典志怪人物，将角色插画延展至海报、明信片与立牌，建立统一的系列视觉。

01 / 主题立项

以《聊斋志异·聂小倩》篇故事角色形象设计为毕业设计主题，探索如何将经典文学中的角色特质、明代服饰与民俗符号转化为当代年轻受众易于理解的视觉语言。项目从角色插画出发，延伸至文创物料与虚幻引擎场景，连接文本阅读、视觉观看和空间体验。

调研与定位

结合原著与传统服饰、首饰资料研读，开展案例分析、问卷调查及玉台寺实地考察。由此确立“古典志怪、传统新生、暗喻符号”三个关键词，以文学内涵为依据，而非仅复刻已有影视角色。

02 / 制作过程

资料归纳与角色草图

使用豆包与 DeepSeek 辅助资料归纳，围绕造型、色彩、道具、场景、服饰建立素材库。通过 AI 工具探索初步想法，再在 Procreate 中绘制精细草图与线稿，确定角色动作、服饰层次及道具关系。

配色探索与手绘成图

利用即梦 AI、可灵等工具辅助草稿配色探索，确定整体色彩基调后，在 Photoshop 中进行手绘上色与细节完善。AI 参与的是构思和配色辅助，成图绘制与排版仍由作者完成。

排版与周边延展

将完成的插画导入 Illustrator，制作海报及周边，再用 InDesign 进行专册、展板和延展物料的规范化排版。成果包含系列海报、角色设计手册、明信片、书签与亚克力立牌。

数字场景探索

场景部分先用 Procreate 确定构图和动线，再在虚幻引擎 5 中搭建白模、配置材质与寺庙模型。结合 Substance 系列制作材质、SpeedTree 构建树木、Niagara 添加粒子效果，最后通过 DaVinci Resolve 进行输出画面的调色。

03 / 设计思路

传统色彩与硬切分语言

从传统画作、明代服饰和参考图中提取中国传统色，以明确轮廓、几何块面与强烈明暗对比塑造人物。结合厚涂肌理，让古典韵味与现代视觉张力并存，而不是简单的扁平归纳或照片复刻。

用符号承载角色叙事

以符号修辞学作为分析框架，从造型、色彩、道具、场景与服饰五个维度提炼人物特征。花枝、面具、符箓与器物不仅是装饰，也参与角色身份和叙事氛围的表达；水墨山形与文字肌理统一系列的志怪意境。

04 / 遇到的问题与解决

资料分散，文学描述难以直接转为图像

问题：原著、影视改编、服饰资料与实地场景提供的信息不同，缺少统一的视觉依据。解决：以造型、色彩、道具、场景和服饰分类整理文献，建立前期素材库；通过寺庙摄影、草图和动线记录补充空间布局信息，将实景作为构建虚构兰若寺的参考，而不是直接等同于原著场景。

角色同质化与传统审美的现代转译

问题：既有影视形象容易影响角色创作，中国传统色的搭配也需要契合人物性格。解决：结合问卷与案例分析确定硬切分风格，从传统画作提取色彩，通过明暗对冲、块面分割和厚涂肌理建立系列语言，再用角色专属服饰、道具与符号强化差异。

单一插画难以承载完整体验

问题：仅以插画呈现，文学设定与文化内涵不易展开。解决：用角色手册补充设计逻辑，用海报、明信片、书签与立牌拓展观看和收藏场景，并通过虚幻引擎场景探索空间氛围的呈现。
