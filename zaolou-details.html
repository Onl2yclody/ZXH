PROJECT DETAIL / PACKAGING 04

灶楼
煲仔饭

ZAOLOU · 品牌包装设计
主题 / THEME

煲仔饭餐饮品牌包装与视觉延展

项目说明 / DESCRIPTION

以粗黑字形、砂锅图形与暖色纸材建立品牌识别，将视觉语言应用于餐盒、纸套、外带纸袋和保温袋。下方展示包装设计思路与成品应用。

01 / 主题立项

以开平煲仔饭为对象，围绕柴火瓦煲与侨乡文化建立餐饮品牌识别。选题从传统烹饪场景和品牌建设需求切入，将地域记忆转化为可延展的视觉系统。

02 / 制作过程

通过文献、问卷、实地与网络调研梳理品牌现状及消费需求，再以思维导图和用户体验地图组织设计方向。随后探索标志、字体、食材图形和吉祥物草图，确定视觉规范，并延展至包装、宣传及餐饮应用。

03 / 设计思路

品牌名“灶楼”结合柴火灶与开平碉楼意象，以“以灶为魂，以楼为根”组织定位。标志融合煲仔饭本体、火焰、砖砌柴火灶和印章式衬托；配色从锅巴、米饭与烹饪场景提取，辅助图形延展为食材、器具、火焰和地域建筑。吉祥物“小煲 X-bao”进一步增加亲近感。

04 / 遇到的问题与解决

调研资料指出，现有餐饮品牌存在品牌建设被忽略、视觉同质化、文化符号表面化，以及系统设计与用户体验缺失等问题。方案以开平地域线索与柴火烹饪符号形成差异化识别，并统一标志、色彩、字体和辅助图形，再通过用户体验地图及多场景应用组织整套品牌系统。

05 / 成品展示

展示包装、餐具、文创物料、宣传海报、线上页面及门店应用，呈现品牌视觉在不同接触点上的延展效果。
