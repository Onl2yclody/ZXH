PROJECT DETAIL / GRAPHIC 06

赤尾
避孕套

REDTAIL · 平面广告设计
主题 / THEME

大广赛赤尾避孕套创意海报

项目说明 / DESCRIPTION

围绕“2小时锁水”的题目要求，以水感与容器的视觉隐喻探索创意，最终采用水彩泳池场景表达顺滑与不外漏的广告主题。下方展示创意草图、AI 探索记录与初稿、完成稿对照。

01 / 主题立项

以赤尾避孕套平面广告为设计对象，从中途干涩这一沟通痛点切入，探索如何将锁水、顺滑的产品诉求转化为直观的视觉意象。

02 / 制作过程

先探索沙漠仙人掌与透明薄膜的组合，再转向安全套外形的泳池意象。使用 AI 生成视觉草图，结合图像编辑调整形状、人物与版面，完成广告文字及品牌信息的整合。

03 / 设计思路

仙人掌方向通过干燥地面与锁水意象建立反差，但写实形象中的刺容易产生不适联想，产品关联也不够清晰。泳池方向采用明亮蓝色、水波与漂浮圈，结合四周的瓷砖边界建立容器与安全感的隐喻，使表达更轻松、直观。

04 / 遇到的问题与解决

AI 草图未能准确生成所需的安全套外形，泳池轮廓需要进一步手动调整。过程记录提出了减少水面装饰、调整人物等改进方向；完成稿将人物改为女性，重新安排广告语的位置，并整合品牌标志和产品图。AI 用于前期视觉探索，完成稿仍需进行人工编辑与排版。

本页展示设计创意及原始过程记录；“2小时锁水”等表述来自项目题目与广告文案，不作为独立验证的产品性能结论。
