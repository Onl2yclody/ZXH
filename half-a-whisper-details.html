PROJECT DETAIL / PACKAGING 02

半句
花语

HALF A WHISPER · 品牌与包装设计
主题 / THEME

香水与香氛品牌视觉及包装设计

项目说明 / DESCRIPTION

以剪纸字形、黑白网点与淡紫色拼贴构建品牌语言，将“让气味，替你说半句。”延展至香水瓶、礼盒和手提袋。

01 / 主题立项

围绕香水与香氛的日常表达，以“半句花语”建立轻盈、含蓄的品牌形象。

02 / 制作过程

现有方案将品牌字标与拼贴图形应用于瓶身标签、礼盒和手提袋。以下三视图展示正面、侧面与背面的视觉关系。

03 / 设计思路

以不规则剪纸字形表现品牌个性，淡紫撕纸色块与黑白网点形成层次。米白纸材和玻璃瓶身保留轻盈感，统一的图形组合贯穿瓶身、礼盒与手提袋。

04 / 遇到的问题与解决

不同载体的面积与比例各异，需要兼顾品牌识别和留白。三视图通过调整字标大小及拼贴位置，保持正面信息清晰，并将辅助图形延续至侧面和背面。
